## Question and unchanged scientific contract

Measure the contribution of allowing semantic generalization, both on fixed
baselines and in combination with adaptive space/time execution. Compare each
ON procedure with its own OFF counterpart on identical observations, protected
tracks, auxiliary knowledge and regional hard requirements.

OFF means all occupied original taxonomy terminal categories are retained in the
candidate with their truthful support/counts. It prohibits semantic coarsening;
it does not remove the taxonomy, hide type information, relabel people, drop a
rare category, or change the hard semantic-loss ceiling. Existing support checks
may reject the entire fixed/adaptive cell-window. Selective contribution
suppression is OFF in both conditions.

Keep the exact local400 configuration, 80 m square/d6 geometry, taxonomy IDs,
labels/costs, root/regional support and loss bounds, 400-ms minimum, 4-s maximum,
central 400-ms duration/age cap, 100-ms extensions, 100-ms sensor cadence, 50-ms
progress clock, ownership/retirement and resource rules. A true 100-ms/no-pooling
baseline is outside this experiment because the frozen minimum is 400 ms.
Only the semantic action mode differs within each ON/OFF pair.

## Utility and query definitions

Use equal-recording TEST macro means and each metric's actual available N, with
IN/OUT worlds separate. Report retention/whole-footprint omission, full-input
J, retained semantic loss, spatial/temporal detail, seal delay/tails and source-
class/regional retained and omitted contributions. For OFF survivors semantic
loss is zero by construction; that alone is not a useful-data claim. With the
same fixed candidate support, OFF output should be contained in ON output.

J=(N_input-N_retained+sum_retained taxonomy_loss)/N_input. It is omission plus
semantic distortion, not privacy or complete application utility. Report class
and regional effects rather than only J. Region attribution of reference input
points must be distinguished from whole-output-footprint policy intersection;
overlapping reporting patches must not be summed as independent populations.

Keep existing 10-m/1-s scalar occupancy queries for continuity. Add a declared
aligned 20-m/400-ms taxonomy-node workload on identical query denominators,
including all-road-user and class/family queries. Its count unit is observation
contributions, not instantaneous occupancy. Reference GT stays private. Exact
answers require identifiable semantic domains and complete public coverage;
missing output remains unknown. Separate any public-only spatial/time estimates
and their coverage/error. Do not assume uniform frequencies among semantic
children or use private type frequencies to repair ambiguous categories.
Taxonomy ancestors/descendants are separate queries, not additive populations.

Native core, subprocess elapsed, source/audit/query and full-series wall time
have different scopes. Imported ON timings and newly executed OFF timings are
not a controlled timing comparison. If such a comparison is needed, run a
separate matched ON/OFF timing check; no live/per-step deadline claim follows.
