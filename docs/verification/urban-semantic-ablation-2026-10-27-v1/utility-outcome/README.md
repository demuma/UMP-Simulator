# Semantic-action ablation: utility outcome

Completed 28 October 2026. All 1,296 new native cases and 144 regional compositions
verify on the original 72 recordings. The seven matched ON/OFF pairs have identical
hard policies and observations. No new movements, targets or source replacements.
MIA has not started for OFF; its TRAIN/CAL fitting and separately published lock
remain the next stage.

The 32 TEST IN recordings show a large coverage cost when semantic generalization
is disabled: mean retained observation contributions fall from 56.16–70.33% ON to
0.09–0.16% OFF. Full-input J rises from 72.78–78.67% to 99.84–99.91%. OFF survivors
have zero taxonomy loss, but that conditional fact does not compensate for the
almost complete omission. This result applies to the declared local400 policy,
class composition and movement streams; it is not universal infeasibility.

Exact category-query coverage is 0.003–0.010% OFF versus 0.583–5.344% ON for the
20 m/400 ms workload. Exact answered counts have zero error; missing answers stay
unknown, so low conditional error is never treated as high utility. Retained
semantic detail, logical delay and count errors retain their metric-specific Ns.
In particular OFF conditional delays/errors often have fewer than 32 recordings.

Temporal First, immediate Semantic First and semantic-wait/Temporal produce
identical normalized OFF payloads on all 144 source/world streams. Spatial First
and semantic-wait/Spatial also match each other; between those two families only
99/144 streams match. These observations are not universal equivalence or extra
independent evidence. All seven declared procedures remain in the study.

## Verified delay-tail correction

Independent source/public reconstruction found that the frozen diagnostic
collector creates delay-counter keys even for zero observations. Its maximum
therefore includes empty scheduled timestamps. In one case the reported value
was 3,100 ms while the maximum among retained observations was 1,700 ms. Weighted
mean, p50, p95 and p99 match exactly under both conventions.

The original rows, reports, features and native outputs remain unchanged. The
[explicit correction](retained-delay-maximum-correction.json) is authoritative
for maxima among actual retained observations; it includes every affected stream
in aggregate with the original available Ns. summary.json retains its original
scheduled-key field for immutable comparison. The independent V2 audit strictly
reproduces all stored diagnostics and separately verifies the positive-observation
profile; it does not relax tolerances. The original failed audit is preserved.
The mean-delay tables and figures are unaffected. MIA predictors are constructed
separately from public output and auxiliary knowledge, not from this utility field.

## Exact environment restoration

After the complete native phase, the first report process failed before importing
application code because the temporary Python environment was missing files.
The damaged environment is preserved locally. The exact original 18 dependency
versions were restored offline from cached wheels at the same interpreter path;
all 3,048 payloads and all 140 surviving original files match. The frozen historical
and current protocol authentication pass, and all 530 Python regressions pass
again. No aggregation case was rerun and no scientific code or input changed.
A subsequent report-only attempt completed. Its original import failure and
minor verification-harness failures remain recorded locally.
